# Support

Microsoft.Identity.Native.Primitives is currently pre-release software.

Only the latest `dev` branch and explicitly published native pre-release builds
are evaluated unless a release states otherwise. No general-availability support
commitment, service-level agreement, servicing window, or backport policy is
implied.

A production support and version-servicing policy will be established before
general availability. After GA, this document can evolve into a formal
supported-version matrix.

## Getting help

- Search or open
  [GitHub Issues](https://github.com/AzureAD/microsoft-authentication-library-for-python/issues)
  for reproducible native bugs and approved feature discussions.
- Read [CONTRIBUTING.md](CONTRIBUTING.md) before proposing or implementing a
  change.
- Review [CHANGELOG.md](CHANGELOG.md) for native user-visible changes.
  MSAL Python package releases do not imply a native release or native support
  commitment.

Do not use GitHub Issues for suspected vulnerabilities. Follow the
[Microsoft Security Response Center reporting process](SECURITY.md).
